# Borozdov Pop

A theme from the Borozdov collection. Two faces — light **Oat**, a sunlit notebook with a
hot-pink highlighter, and dark **Licorice**, the same notebook on black paper. Oat paper,
white pillows at 44px, heavy italic headlines and one magenta for what you act on.

![Borozdov Pop in light mode](https://raw.githubusercontent.com/borozdov-obsidian-themes/pop/main/screenshots/light.png)

![Borozdov Pop in dark mode](https://raw.githubusercontent.com/borozdov-obsidian-themes/pop/main/screenshots/dark.png)

## Principles

- **A poster voice.** Inter Black Italic at line-height 1 for the title, the two largest
  headings and pull quotes — the heavy slope is what makes it editorial rather than
  corporate. The platform's own sans carries everything else.
- **One hot magenta.** The main button, a checked task, a toggle, the caret and the open
  file; links take a deeper magenta that can carry text. Nothing else is chromatic.
- **Pillows.** Callouts, embeds and modals are white pillows with 44px corners and a soft
  diffused shadow; buttons, fields and tags are pills; checkboxes are round.
- **Warm grey on oat.** The canvas is oat paper, never white; text is ink, muted text
  charcoal, and tags are dark bands with oat text.

## Features

- Light and dark modes, following Settings → Appearance → Base color scheme
- Callouts as white pillows with the title in the type's colour
- Pull quotes in the poster voice, a size up, with no rule
- Tags and property values as dark-band pills that turn magenta on hover
- Quiet editing: no focus ring around the note, its title or form fields while you type;
  property names read as labels, not boxed fields
- Text colours meet WCAG contrast on both faces
- The phone layout keeps the same colours and shapes
- No `!important`: every rule can be overridden with a CSS snippet

## Installation

**From the community directory:** Settings → Appearance → Themes → Manage, search for
**Borozdov Pop**, then **Install and use**.

**By hand:** download `manifest.json` and `theme.css` from the
[latest release](https://github.com/borozdov-obsidian-themes/pop/releases/latest) into
`<vault>/.obsidian/themes/Borozdov Pop/`, then choose Borozdov Pop under
Settings → Appearance → Themes.

## Font

Inter Black Italic (© 2016 The Inter Project Authors) is embedded in `theme.css` as base64
WOFF2 under the SIL Open Font License 1.1 — see [`fonts/OFL.txt`](fonts/OFL.txt). One
style, Latin and Cyrillic, for the title, the two largest headings and pull quotes only.
